## 4. Projects section

Add each one under **Add profile section → Recommended → Add projects**.

### MCB Bank Stock Prediction — Random Forest Model

```
Built and iteratively refined a Random Forest model predicting next-day MCB Bank (PSX) stock returns, engineering 89 features across price momentum, technical indicators, macroeconomic variables and sector data.

Achieved 56.6% walk-forward directional accuracy — beating baseline in 13 of 15 quarters — and a backtested Sharpe ratio of 2.03. Validated results using SHAP, permutation and MDI feature-importance methods.

Tools: Python, scikit-learn, time-series cross-validation
```

### Diminishing Musharakah Financing Model

```
Modelled a PKR 1 billion Shariah-compliant commercial property financing structure for a PSX-listed company, building a full 7-year rental-sharing and equity buyback schedule.

Conducted a six-category risk assessment with Shariah-compliant mitigations, and benchmarked the structure against conventional loan financing.

Tools: Financial modelling, Excel, Islamic finance structuring
```

### Predictive Modelling on Insurance & Customer Data

```
Built a linear regression model predicting insurance charges from policyholder data, supported by exploratory analysis covering distribution, outlier and correlation analysis.

Applied K-Nearest Neighbors with feature scaling to a customer dataset for similarity and pattern analysis.

Tools: Python, pandas, scikit-learn, seaborn, matplotlib
```

### Financial Literacy & Saving Behaviour — Statistical Study

```
Co-designed and fielded a 15-item survey (n = 86) measuring financial literacy and saving behaviour among university students.

Ran reliability (Cronbach's alpha), normality, correlation and regression tests in SPSS, finding that financial literacy explains 46% of the variance in saving behaviour (R² = 0.462, p < 0.001).

Tools: SPSS, survey design, hypothesis testing
```

### School Management System — Relational Database Design

```
Designed a 22-table relational database schema covering attendance, library, fee, examination, transportation and hostel-management modules.

Implemented primary-key-based table structures and populated the schema with sample records for query testing.

Tools: SQL (T-SQL / SQL Server)
```
